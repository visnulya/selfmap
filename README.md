# SelfMap

Адаптивный лонгрид на React + Vite по утверждённым макетам 1440 × 6269 и 402 × 4980. Оригинальные изображения и шрифты находятся в `public/`, runtime-данные — в `src/data/`. Загрузка из Figma во время работы сайта не требуется.

Сохранены пять согласованных эффектов: появление Гермеса и его диалога, раскрытие схемы «Ты», сообщения античных персонажей, прорисовка исходной трещины и hover кнопки. Scroll-анимации однократные; предусмотрен `prefers-reduced-motion`. Hover включён только для устройств с подходящим указателем.

## Запуск и production-сборка

В GitHub Actions используется Node.js 22.

```sh
npm ci
npm run dev
```

Разработка: `http://127.0.0.1:5173/selfmap/`.

```sh
npm run build
npm run preview
```

Сборка находится в `dist/`. Локальный просмотр production: `http://127.0.0.1:4173/selfmap/`. Vite preview предназначен только для локальной проверки.

## GitHub Pages

Репозиторий: https://github.com/visnulya/selfmap

Ожидаемый адрес **после успешной публикации**: https://visnulya.github.io/selfmap/

В `vite.config.js` установлен `base: '/selfmap/'`. Изображения используют `import.meta.env.BASE_URL`; Vite добавляет base к CSS и собранным ресурсам. Не заменять адреса на пути от корня домена `/assets/...` или `/fonts/...`.

Workflow `.github/workflows/deploy.yml` при push в `main` выполняет `npm ci`, собирает проект и публикует только `dist` через GitHub Pages. Перед первой публикацией выбрать в Settings → Pages → Source значение **GitHub Actions**. Подробности и порядок обновления: [DEPLOYMENT.md](DEPLOYMENT.md).

## Ссылки

Все адреса находятся в `src/data/links.js`. Дзен подключён к `https://dzen.ru/selfmap` и открывается в новой вкладке с `noopener noreferrer`. Остальные площадки, политика конфиденциальности и страница сервиса имеют `url: null` и пока не выполняют переходов. Для подключения настоящего адреса достаточно изменить конфигурацию.

## Проверки

В отдельном терминале запустить `npm run preview`, затем:

```sh
npm run check:production
```

Проверка сравнивает все файлы `public/` с выдачей сервера, проверяет шрифты, загрузку ресурсов, геометрию и завершение scroll-анимаций. Проверка Дзена, hover и пяти эффектов на шести ширинах, в PowerShell:

```powershell
$env:SELFMAP_URL = 'http://127.0.0.1:4173/selfmap/'
npm run check:links
```

На Windows используется установленный Chrome; другой путь можно задать через `SELFMAP_CHROME`. На других системах проверкам нужен Chromium для Playwright (`npx playwright install chromium`). Отчёты и скриншоты остаются в локальном `artifacts/`.

Перед отправкой staged-файлов выполнить `npm run check:publication`: проверяются исключённые каталоги, резервные архивы, размер файлов и типовые шаблоны секретов. Исторические проверки `check:visual`, `check:intro`, `check:scheme` используют локальные эталоны из `design/` и `artifacts/`; для работы сайта эти эталоны не нужны и в GitHub не отправляются.

## Сохранения и обновления

Контрольные точки создаются скриптом `scripts/save-checkpoint.ps1` и проверяются по SHA-256. Архивы из `checkpoints/` не отправляются в GitHub. Версия перед подготовкой к публикации сохранена как `SelfMap — Final Version Before GitHub Publication — 2026-10-25_03-48-55.zip`. Предыдущие локальные архивы сохранены.

Для обновления через Codex: «Обнови SelfMap: … Сохрани согласованный дизайн и анимации, проверь production-сборку, покажи изменения и после моего подтверждения отправь обновление в main». После push workflow автоматически обновляет Pages. Не использовать force push, существующую историю сохранять.

Для восстановления распаковать выбранный архив в отдельную пустую папку, выполнить `npm ci` и `npm run dev`. Текущая папка проекта при этом остаётся на месте.
